# Support

## Documentation

Start with the [README](https://github.com/Cliftonz/tandoor-recipe-mcp#readme). It covers installation, configuration, tool sections and remote mode.

## Questions and bugs

Open a [GitHub issue](https://github.com/Cliftonz/tandoor-recipe-mcp/issues/new/choose). For a bug, use the bug report template.

Include:

- The server version
- How you installed it: Claude plugin, Claude Desktop extension, npm or Docker
- Local or remote mode
- Your Tandoor version
- The tool you called, what you expected and what happened
- Relevant log lines from standard error

Never paste API tokens, OAuth tokens or `TANDOOR_MCP_SECRET_KEY`. Remove them from logs and configuration before you post.

## Security problems

Do not open a public issue. Follow [SECURITY.md](SECURITY.md).
